# Chromecast Remote v0.11.0

Android version **0.11.0**, build **13**.

## New features

- Phone keyboard preview: masked local drafts, explicit Send, separate Enter, and invalidation when the TV field, app or connection changes.
- Per-TV eyes-up mode, room labels, household power/volume preferences, and an explicit volume compatibility check.
- Manual room suggestions and active/nearby/recent ordering of saved TVs.
- YouTube and Spotify destination templates alongside personal links and per-TV favorites.
- Optional Home Assistant routines: verify an audio volume preset before requesting a TV app launch, with confirmation, cancellation and partial-outcome feedback.
- Reported TV power and volume with freshness labels; disconnected sessions clear their reports.
- Cast capability checks through a native bridge, pause gating and bounded seeking for supported live/VOD sessions.
- Local measurements in Settings, explicit copy/clear, and no automatic upload.

## Reliability and accessibility

Outgoing remote traffic now keeps an active connection from being incorrectly timed out when a TV stops idle pings. The directional pad has distinct accessible targets and focus order. Cast status transitions respect reduced motion.

Release signing now uses explicit private configuration and preserves the existing signing certificate. Install the APK over the existing app to retain its data; uninstalling is unnecessary.

## Validation

- Static analysis: no issues; **128 tests passed**.
- Android debug and release builds passed.
- Package/version, APK signature and certificate continuity against v0.10.0 verified.
- Emulator update from v0.10.0 retained a custom destination and its favorite status.
- Remote/keyboard layouts reviewed using fake-controller captures; release Apps navigation and retained data checked in the emulator.

## Compatibility boundaries

Keyboard input remains a preview. Physical-TV text behavior, sensitive fields, power/audio reporting, provider playback, Cast live media, and Home Assistant integration require device testing. Room suggestions use manual labels, not physical room sensing. Cancelling a routine cannot undo a volume change already sent.

An iOS 15 source project is included, but no iOS binary is released: Xcode is unavailable on this machine, so the project has not been compiled, signed or device-tested. Complete TalkBack/VoiceOver and physical-device performance/usability validation also remain open.

See [implementation status](../UPGRADE_IMPLEMENTATION_STATUS.md) and [release readiness](../RELEASE_READINESS.md) for exact delivery and verification boundaries.
