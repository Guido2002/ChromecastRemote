# Chromecast Remote v0.10.0

Version: 0.10.0

Android build: 12

Date: 29 October 2026

## Main changes

- Open directly into the last paired TV remote, with Remote, Apps, and Devices sharing one session.
- Keep navigation, play/pause, mute, and volume together; use the full visible D-pad quadrants.
- Launch apps directly from the library and manage ordered favorites independently for each TV.
- Add personal app and content destinations to the same searchable library.
- Preserve a disconnected app-launch request and confirm its destination after selecting a TV.
- Distinguish a launch request from a confirmed foreground app; remove timed automatic Play Store selection.
- Combine saved TVs and nearby devices, with separate labels and persistence for Cast receivers.
- Improve endpoint rediscovery, fresh pairing credentials, connection cancellation, and unexpected-disconnect notification.
- Keep Android TV discovery available independently of Cast initialization.
- Add Android Quick Settings and launcher shortcuts to open Remote.
- Improve button contrast, large-text layouts, pairing input, connection help, and reduced-motion behavior.
- Use accurate Search, foreground-app, and Stop casting labels. Make update notices nonblocking.

## Updating

Install the APK over the existing app to retain saved pairings and preferences. This release retains the signing identity used by v0.9.0. Existing global favorites migrate into independent TV preferences when those TV scopes are first used.

NPO Start and unknown package shortcuts may open a store page. Select Open on the TV if needed; the app no longer sends an automatic confirmation key.

## Validation and limitations

Static analysis is clean and all 92 automated tests pass, including local TLS lifecycle, session, migration, launch, and responsive-layout checks. The Android release APK is verified for package identity, version, and signing continuity.

Physical TV pairing, standby, application-specific controls, Cast playback, external receiver volume, and TalkBack still need representative hardware validation. Android TV foreground-app reporting does not provide playback state. Phone keyboard and voice streaming are not implemented.

This is a GitHub-distributed Android APK using the repository's existing signing configuration. A separately managed production signing identity and an iOS build are outside this release.

See [implementation status](../UPGRADE_IMPLEMENTATION_STATUS.md) for the remaining roadmap and verification gates.
